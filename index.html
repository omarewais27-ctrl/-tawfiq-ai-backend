اتصال مساعد AI حقيقي

لأمانك، ما تحطّش مفتاح API سري جوه ملف HTML بيتوزع على الناس. الربط القوي يحتاج وسيط Backend يحتفظ بالمفتاح ويرسل الطلبات للنموذج. أدخل رابط خادمك الآمن هنا. يجب أن يقبل POST JSON بالشكل {"message":"...","mode":"explain","subject":"عربي"} ويرجع JSON فيه answer أو output أو reply. لا تضع مفتاح النموذج السري في هذا الملف.

اكتب نفس الكود ده بالظبط على أي جهاز تاني عشان تنزّل بياناتك عليه. محدش يقدر يوصل لبياناتك من غيره.
